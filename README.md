# Projeto Cordel

Um projeto simples, desenvolvido durante os estudos de HTML5 e CSS3 do curso do Gustavo Guanabara, recriando um site em estilo cordel com efeito parallax.

## 🔗 Acesse o projeto

🌐 [Visualizar Projeto](https://vickmoraisdev.github.io/projeto-cordel/)

## 📚 Sobre o projeto

O objetivo deste projeto foi praticar:

- Estruturação semântica com HTML5
- Estilização com CSS3
- Uso de imagens de fundo
- Efeito parallax com `background-attachment`
- Responsividade
- Tipografia personalizada

O site apresenta um poema em estilo cordel com um visual inspirado na literatura nordestina.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3

## 🎯 Aprendizados

Durante o desenvolvimento deste projeto, pratiquei principalmente:

- Posicionamento de elementos
- Trabalhar com viewport (`vh`)
- Uso de variáveis em CSS
- Sombras e contraste em textos
- Organização de estilos
